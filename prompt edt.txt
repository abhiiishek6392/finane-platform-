# AI Prompt for Recreating the Finance Platform .

# Context and Role

You are a Senior Full-Stack Developer and Software Architect specializing in scalable fintech applications using modern JavaScript technologies. Your task is to recreate a complete AI-powered financial management platform. The application must replicate the architecture, workflows, features, folder structure, and user experience of a modern finance platform built with Next.js 15, Prisma, PostgreSQL, Clerk authentication, AI integrations, event-driven background jobs, and responsive dashboard interfaces.

The goal is to build a highly polished, full-stack finance management application that supports secure authentication, account management, transaction tracking, AI-powered receipt scanning, budget analytics, recurring transaction automation, email notifications, and intelligent financial insights.

The system should follow clean architecture principles, production-ready coding standards, modular folder organization, reusable UI patterns, and scalable backend logic.
